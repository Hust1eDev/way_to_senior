# Way2Senior

Учебный проект для развития Python и архитектурного мышления до уверенного Senior-уровня.

Основной фокус: ООП, ответственность объектов, границы компонентов и обоснование архитектурных решений.

## Исходный опыт и точка входа

Python, asyncio, PostgreSQL, SQLAlchemy, Django, FastAPI, REST API, Telegram-боты, торговые системы и парсеры.

Главный заявленный пробел: ООП и архитектура приложений. По твоим словам, около года ты не писал код самостоятельно и часть привычек и синтаксиса забылась. Практический уровень пока не оценивался.

Начинаем с короткой разминки по общему Python, затем переходим к ООП. Темп выбираем по твоим решениям.

## Правила обучения

1. Задачи и тесты решаешь ты. Наставница не пишет готовые решения.
2. После сдачи я провожу подробное code review: корректность, подход к задаче, читаемость, проверки, затем ООП и архитектура.
3. Для каждой существенной ошибки объясняю последствия и даю направление для самостоятельного исправления.
4. Сначала ты получаешь возможность исправить код самостоятельно. Подсказки усложняются постепенно, если они нужны.
5. Примеры и задания связаны с backend-разработкой.
6. Код и тесты запускаю локально, когда это помогает проверке. Результаты запуска отделяю от выводов по чтению кода.
7. Твой код без разрешения не изменяю. Запрос на review сам по себе не разрешает правки.
8. Темы, задания, ошибки и подтвержденный прогресс фиксирую в [LEARNING.md](LEARNING.md). Код при этом не меняю.

Общаемся по-русски. Идентификаторы Python пишем по-английски.

## Как проходит задание

1. Прочитай требования и кратко объясни ожидаемое поведение.
2. Напиши свое решение и проверь его. В первых трех заданиях разминки достаточно собственных ручных проверок, с четвертого добавляем unittest.
3. При сдаче укажи файлы, команду запуска, результаты проверок и то, что вызвало затруднения.
4. Получи review с указанием места, проблемы, последствий и направления исправления.
5. Исправь замечания самостоятельно и сдай повторно.

Задание принимается после проверки поведения и объяснения решения. Чтение материалов само по себе не закрывает тему.
