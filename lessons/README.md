Задания выполняются последовательно. После каждого задания следует review и, при необходимости, самостоятельное исправление. Объем следующего задания уточняем по результатам.

Условия находятся в Markdown-файлах модуля. Python-файлы с решениями создаешь ты. В первых трех заданиях разминки достаточно ручных проверок; с четвертого используем автоматические тесты в [tests/](../tests/README.md).
