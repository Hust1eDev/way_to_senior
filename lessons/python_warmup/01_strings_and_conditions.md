# PY-01. Строки и условия

Статус: выдано. Решение еще не написано.

## Контекст

Telegram-бот приветствует пользователя. Имя иногда приходит пустым или с лишними пробелами.

## Задание

Самостоятельно напиши функцию make_greeting(name). Она получает строку и возвращает строку приветствия.

Требования:

1. Начальные и конечные пробельные символы в имени удаляются.
2. Если после этого имя пустое, результат: Привет, гость!
3. В остальных случаях результат: Привет, <имя>!
4. Регистр букв и пробелы внутри имени сохраняются.
5. Функция возвращает результат. Печать при ручной проверке может быть снаружи функции.

В этой задаче вход всегда строка. Обработку других типов пока не добавляй.

## Примеры поведения

В таблице использованы кавычки для обозначения границ строки. Они не входят в результат.

| Вход | Ожидаемый результат |
| --- | --- |
| "Анна" | "Привет, Анна!" |
| "  Анна  " | "Привет, Анна!" |
| "" | "Привет, гость!" |
| "   " | "Привет, гость!" |
| "Анна Мария" | "Привет, Анна Мария!" |
| "аННа" | "Привет, аННа!" |

## Короткое напоминание

Аргумент функции передает ей входное значение. Возврат дает вызывающему коду результат, который можно дальше использовать. Условие позволяет выбрать поведение в зависимости от данных.

Если забыл синтаксис функции или работу со строками, спроси об одной конструкции. Я объясню ее на отдельном примере.
