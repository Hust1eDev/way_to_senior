# Модуль 00. Разминка по Python

Цель: восстановить привычку самостоятельно писать и проверять код, затем плавно перейти к ООП.

У тебя уже есть практический опыт. Сейчас проверяем, что вспоминается легко, а что нужно повторить. Скорость и объем следующих заданий выбираем после review.

## План

| ID | Темы | Практика |
| --- | --- | --- |
| [PY-01](01_strings_and_conditions.md) | Строки, условия, аргумент и возврат функции | Подготовить приветствие для пользователя бота |
| PY-02 | Списки, циклы, счетчики | Подсчитать успешные, ошибочные и прочие статусы ответов |
| PY-03 | Словари, ссылки на объекты, разделение на функции | Отобрать и упорядочить заявки без изменения входного списка |
| PY-04 | Преобразование типов, исключения, unittest | Проверить входное значение и покрыть допустимые и ошибочные случаи |
| PY-05 | Небольшая программа из функций, изменяемое состояние | Создавать, комментировать и закрывать заявки на словарях |

Подробные условия PY-02 - PY-05 выдаем по очереди и уточняем по предыдущим решениям. Сейчас выполняем только PY-01.

## Как работаем

- Ты пишешь код самостоятельно.
- В первых трех заданиях достаточно собственных ручных проверок с ожидаемыми и фактическими результатами.
- С четвертого задания добавляем unittest.
- Если забыл конструкцию или метод, можно спросить точечную подсказку. Подсказка не считается ошибкой.
- Я объясняю замечания, а исправления сначала делаешь ты.

Для разминки достаточно стандартной библиотеки. Классы, фреймворки, БД и внешние API пока не нужны.

## Переход к ООП

Сначала решим небольшой сценарий с заявками через словари и функции. Затем в [модуле ООП](../oop/README.md) разберем, как класс помогает связать данные с поведением и сохранять правила состояния.

Критерий готовности к переходу: ты самостоятельно пишешь небольшие функции, работаешь с коллекциями, объясняешь изменения данных и проверяешь обычные и ошибочные случаи.
