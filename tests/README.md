# Тесты учебных решений

Тесты пишешь ты. Готовых тестов и решений в проекте пока нет.

В первых трех заданиях [разминки](../lessons/python_warmup/README.md) достаточно собственных ручных проверок. Указывай ожидаемый результат и то, что получилось при запуске.

С четвертого задания разминки и в [модуле ООП](../lessons/oop/README.md) используем unittest из стандартной библиотеки. Дополнительные зависимости не нужны.

Файлы автоматических тестов размещай непосредственно в tests/. Для разминки используй имена test_python_04.py, test_python_05.py, для ООП - test_oop_01.py и далее. Внутри используй тестовые случаи unittest.TestCase.

Запуск всех тестов из корня проекта:

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

Запуск только первого задания ООП:

```bash
python3 -m unittest discover -s tests -p 'test_oop_01.py' -v
```

Проверяй наблюдаемое поведение и сохранение правил. Не привязывай тесты к именам внутренних атрибутов или конкретному способу хранения данных.

Изолируй состояние тестов: каждый сценарий создает собственные данные и объекты. Нужные проверки перечислены в условиях задания.

Результат с нулем тестов не считается подтверждением работоспособности. При сдаче с автоматическими тестами указывай команду, число выполненных тестов и фактический результат.
